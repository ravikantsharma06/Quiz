# 🧠 Quiz App

An interactive and user-friendly quiz application designed to make learning fun, engaging, and accessible. Test your knowledge, practice different questions, and enjoy a simple online quiz experience.

🔗 **Live Demo:** [Play Quiz Online](https://quiz-kappa-one-99.vercel.app/)

---

## ✨ Features

- 🎯 Interactive quiz experience
- 💻 Simple and user-friendly interface
- 📱 Responsive design for different screen sizes
- ⚡ Fast and lightweight web application
- 🎨 Clean styling and intuitive navigation
- 🌐 Accessible directly through a web browser

## 🛠️ Technologies Used

- **HTML** — Structure of the application
- **CSS** — Styling and responsive layout
- **JavaScript** — Interactive functionality and quiz logic
- **Vercel** — Deployment and hosting
- **GitHub** — Source code management
